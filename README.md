# WordQuest · 单词冒险岛测试版

四年级上册英语已开放 Unit 1、Unit 2，共 70 个词条、11 组，支持自由选组。Unit 1 为 30 词（5、5、7、7、6）；Unit 2 为 40 词（7、8、6、7、7、5）。Unit 3–6 显示准备中。

- 选择分组 → 配对预热 → 每词五关 → 组末混合复习 → 学习下一组。
- 每组进度独立保存，旧第一组的学习记录和积分保留。
- 第一、第二关自动读单词，第四关自动读练习句，手动播放按钮保留。
- 第三关点击开始录音，读完结束或 8 秒自动结束后继续，不识别文字或判断对错。录音在本机临时处理，不上传、不保存。
- 第四关用乱序字母拼词，短语空格、连字符和标点固定；第五关仅键盘拼写，提供格式提醒，不含手写识别。Mr 按 mister 朗读。
- 第一单元首次完成 600 XP，第二单元新增 800 XP，共 1,400 XP；复习和重学不重复奖励，切换单元不清除旧记录。
- 教材释义与词典读音来源分别记录；例句由项目编写，页面标注。本版不包含 because of sb / sth。

学习进度只在当前浏览器保存，未跨设备同步。iPhone 可能要求手动启动首次音频播放，真实手机/iPad 表现以设备测试为准。

本仓库只包含网站运行文件和许可证，不包含开发源码、测试报告、用户截图、教材扫描件或原始词库。依赖许可证见 `licenses/` 与 `THIRD_PARTY_NOTICES.md`。
