# WordQuest · 单词冒险岛测试版

小学英语单词学习网站的 GitHub Pages 测试发布包。

- 第一组：sport、jump、high、far、ping-pong。
- 流程：中文配对 → 每词五关 → 小组复习。
- 页面提供单词朗读、选择题、跟读、乱序字母填句、键盘和本机手写默写。
- 手写数据不上传；首次识别需加载本机模型和 WebAssembly 运行文件。
- 学习进度只保存在当前浏览器，不跨设备同步。

本仓库仅包含网站运行所需的发布文件，不包含开发记录、用户截图或测试笔迹。第三方模型和运行库许可证见 `models/`、`licenses/` 及 `THIRD_PARTY_NOTICES.md`。

浏览器语音支持、网络服务和真实手机/iPad 的表现以实际测试为准。
